## Overview

OSS Open Source Repository Browser aims to scale the work originally done by the UC Santa Cruz OPSO for the web. The product gathers and aggregates Github data from universities and research institutions represented in CURIOSS. This data is visualized into interactive dashboards and queryable via advanced filtering features.
