## Overview

OSS' [fork](https://github.com/oss-slu/repoexplorer) of [repoexplorer](https://github.com/UC-OSPO-Network/repoexplorer) (which includes the work from [repofinder](https://github.com/UC-OSPO-Network/repofinder)) is a Typescript rebuild of the Python/Shiny projects originally built by [Juanita Gomez](https://www.linkedin.com/in/juanitagomezr/) with the [UC OSPO Network](https://ucospo.net/). Our fork follows a client-server model with a React frontend and REST API backend that is more scalable for the web. A Typescript CLI is also included as a reimplementation of the Github scraping and LLM data classification functionalities from the [repofinder](https://github.com/UC-OSPO-Network/repofinder) project. Our reimplementation takes advantage of a local LLM and a Postgres database, making it possible to update the application's data on a regular basis.
