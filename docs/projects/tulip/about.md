## Overview

TULIP is a web-based unified legal intake portal created in partnership with the SLU School of Law Legal Clinics Program to streamline the intake process for clients seeking legal assistance.

### User Guide

**TULIP (Trusted Unified Legal Intake Portal)** is a web application created in partnership between OSS and the SLU School of Law Clinic Program. It is a digital intake portal for all clinics within the program to replace the current paper-based intake system. Case-assignment workflows are standardized through this tool for more efficient document management.

## Technical Information

### 📘 Overview

**TULIP** is an open-source platform with the following stack:

- **Frontend**: [React](https://reactjs.org/)
- **Database**: [PostgreSQL](https://www.postgresql.org/)

The project is designed to store legal intake form submissions from clients and automatically direct them to the correct clinic.
